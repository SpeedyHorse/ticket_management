# 要件文書

## 概要

チケット管理システムは、コンサートやイベントのチケット販売・管理を効率化するためのWebアプリケーションです。イベント主催者はチケットの作成、販売管理、購入者管理を行うことができ、顧客はチケットの購入、確認、管理を実現します。

## 要件

### 要件 1

**ユーザーストーリー:** イベント主催者として、新しいイベントのチケットを作成したいので、顧客にチケットを販売することができる

#### 受け入れ基準

1. WHEN 主催者が「新規イベント作成」ボタンをクリック THEN システムは イベント作成フォームを表示する
2. WHEN 主催者がイベント名、開催日時、会場、チケット価格、販売枚数を入力してフォームを送信 THEN システムは 新しいイベントを作成し、一意のIDを割り当てる
3. WHEN イベントが正常に作成された THEN システムは 成功メッセージを表示し、イベント管理画面にリダイレクトする
4. IF 必須フィールドが未入力 THEN システムは エラーメッセージを表示し、フォーム送信を拒否する

### 要件 2

**ユーザーストーリー:** 顧客として、利用可能なイベントのチケットを閲覧したいので、興味のあるイベントを見つけることができる

#### 受け入れ基準

1. WHEN 顧客がチケット一覧画面にアクセス THEN システムは 販売中の全てのイベントをリスト形式で表示する
2. WHEN 顧客がイベントをクリック THEN システムは イベントの詳細情報（日時、会場、価格、残り枚数）を表示する
3. WHEN イベント一覧が表示される THEN システムは 各イベントの名前、開催日時、会場、価格、販売状況を表示する
4. WHEN 売り切れのイベントが表示される THEN システムは 「売り切れ」ステータスを明確に表示する

### 要件 3

**ユーザーストーリー:** 顧客として、チケットを購入したいので、イベントに参加することができる

#### 受け入れ基準

1. WHEN 顧客がイベント詳細画面で「チケット購入」ボタンをクリック THEN システムは 購入フォームを表示する
2. WHEN 顧客が購入枚数、購入者情報を入力して決済を完了 THEN システムは チケットを発行し、購入確認メールを送信する
3. WHEN チケットが購入された THEN システムは 一意のチケット番号を生成し、QRコードを含むデジタルチケットを作成する
4. IF 在庫が不足している THEN システムは エラーメッセージを表示し、購入を拒否する
5. IF 決済が失敗した THEN システムは エラーメッセージを表示し、購入プロセスを中断する

### 要件 4

**ユーザーストーリー:** 顧客として、購入したチケットを確認・管理したいので、イベント当日にスムーズに入場できる

#### 受け入れ基準

1. WHEN 顧客がマイページにアクセス THEN システムは 購入済みチケットの一覧を表示する
2. WHEN 顧客がチケットをクリック THEN システムは チケットの詳細情報とQRコードを表示する
3. WHEN チケット詳細が表示される THEN システムは イベント名、開催日時、会場、座席情報、チケット番号を表示する
4. WHEN 顧客が「チケットをダウンロード」をクリック THEN システムは PDFまたは画像形式でチケットをダウンロード可能にする

### 要件 5

**ユーザーストーリー:** イベント主催者として、チケット販売状況を確認したいので、イベント運営を適切に管理できる

#### 受け入れ基準

1. WHEN 主催者が管理画面にアクセス THEN システムは 自分のイベント一覧と販売状況を表示する
2. WHEN 主催者がイベントをクリック THEN システムは 詳細な販売レポート（売上枚数、売上金額、購入者リスト）を表示する
3. WHEN 販売レポートが表示される THEN システムは リアルタイムの在庫状況と売上統計を表示する
4. WHEN 主催者が購入者リストを確認 THEN システムは 購入者の名前、購入枚数、購入日時を表示する

### 要件 6

**ユーザーストーリー:** イベント主催者として、イベント情報を編集したいので、変更があった場合に対応できる

#### 受け入れ基準

1. WHEN 主催者がイベント管理画面で「編集」ボタンをクリック THEN システムは イベント編集フォームを表示する
2. WHEN 主催者がイベント情報を変更して保存 THEN システムは 変更内容を保存し、購入者に変更通知メールを送信する
3. WHEN 主催者がイベントをキャンセル THEN システムは 全購入者に返金処理を行い、キャンセル通知を送信する
4. IF 既にチケットが販売されている場合の価格変更 THEN システムは 警告メッセージを表示し、確認を求める

### 要件 7

**ユーザーストーリー:** イベントスタッフとして、入場時にチケットを検証したいので、不正入場を防止できる

#### 受け入れ基準

1. WHEN スタッフがQRコードスキャナーでチケットをスキャン THEN システムは チケットの有効性を検証する
2. WHEN 有効なチケットがスキャンされた THEN システムは 入場許可メッセージと購入者情報を表示する
3. WHEN 無効なチケットがスキャンされた THEN システムは エラーメッセージを表示し、入場を拒否する
4. WHEN 既に使用済みのチケットがスキャンされた THEN システムは 重複使用警告を表示する
